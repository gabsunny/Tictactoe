# Jogo da Velha Wakfu

Jogo da velha com Yugo (X) e Nox (O). Páginas: Home, História e Dicas.
Feito com HTML, CSS, JavaScript e Bootstrap 5 (via CDN).

## Fotos dos personagens
Coloque na pasta `img/` os arquivos `yugo.png` e `nox.png`.
Enquanto eles não existirem, o jogo mostra um desenho simples no lugar.

## Arquivos
- index.html, historia.html, dicas.html
- css/style.css
- js/jogo.js
